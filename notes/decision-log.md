# Decision Log

Use this file to record important project decisions instead of silently changing assumptions.

## How to use this log

- Add an entry when a decision changes the organization's scope, data use, risk, or controls.
- Record uncertainty instead of pretending to know the answer.
- Update the reasoning when new evidence changes the decision.
- Keep confidential or real-world employer information out of the repository.
