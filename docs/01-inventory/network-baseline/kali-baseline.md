## Purpose

This Kali VM is an authorized security-testing workstation for validating Blue Arbor network segmentation, access controls, logging, vulnerability management, and incident-detection capabilities.

It is not a production server and must not store real customer, payment, employee, or University of Michigan information.

## Intended trust-zone placement

The Kali VM should reside in a dedicated security-testing or administrative zone. Firewall rules should permit testing only against explicitly authorized homelab targets and should prevent unnecessary access to management systems and unrelated networks.

## Security requirements

- Use the VM only for authorized homelab testing.
- Keep Kali and installed tools updated.
- Do not store production or employer data.
- Restrict administrative access.
- Do not expose remote-management services directly to the internet.
- Create a snapshot before major testing or tool changes.
- Send relevant operating-system and security events to the future SIEM.
- Document each test's target, purpose, authorization, date, and outcome.
- Prevent the VM from scanning networks outside the authorized homelab scope.
